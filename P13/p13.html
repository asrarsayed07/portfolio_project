A simple guide

Choose the right layout tool

Use Grid to shape the overall page. Use Flexbox to line up elements inside each part.

Explore the guide
01

Grid

Best for layouts with rows and columns, such as cards or a page with a sidebar.

02

Flexbox

Best for a row or column of items, such as navigation links or buttons.

03

Use both

Grid and Flexbox work well together. Choose based on what each container needs to do.
